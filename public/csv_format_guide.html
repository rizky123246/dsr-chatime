CSV Format Guide - Import Data Penjualan

Berikut adalah format CSV yang diharapkan untuk import data penjualan (26 kolom):

Struktur Kolom (26 Columns)

No Column Name Required Format Contoh Description
1 created_date ✓ Required YYYY-MM-DD 2024-01-15 Tanggal transaksi
2 created_time ✓ Required HH:MM:SS 10:30:00 Waktu transaksi
3 order_no Optional Text ORD001 Nomor order (auto-generate jika kosong)
4 receipt_no Optional Text RCP001 Nomor receipt (auto-generate jika kosong)
5 invoice_reference Optional Text INV001 Referensi invoice
6 void Optional TRUE/FALSE FALSE Status void transaksi
7 site_code Optional Text CGI01 Kode lokasi (default: CGI01)
8 site_description Optional Text Chatime Grand Indonesia Nama lokasi
9 article_code Optional Text PMT001 Kode artikel (auto-generate jika kosong)
10 article_name ✓ Required Text Pearl Milk Tea Nama produk
11 quantity ✓ Required Number 2 Jumlah quantity (harus > 0)
12 original_price Optional Number 25000 Harga asli (default: net_price)
13 net_price ✓ Required Number 25000 Harga bersih (harus > 0)
14 promotion_amount Optional Number 0 Jumlah promo
15 promotion_code Optional Text PROMO10 Kode promo
16 promotion_name Optional Text 10% Off Nama promo
17 promotion_channel Optional Text In-Store Channel promo
18 department_code Optional Text BEV001 Kode department
19 department_name Optional Text Beverages Nama department
20 commodity_code Optional Text TEA001 Kode komoditas
21 commodity_name Optional Text Tea Based Nama komoditas
22 merchandise_code Optional Text MTC001 Kode merchandise
23 merchandise_name Optional Text Milk Tea Category Nama merchandise
24 product_group_code Optional Text PMT001 Kode grup produk
25 product_group_name Optional Text Pearl Milk Tea Nama grup produk
26 [EMPTY] Optional - Kolom ke-26 (dibiarkan kosong)

Important Notes

  • Kolom wajib: created_date, created_time, article_name, quantity, net_price
  • Quantity dan net_price harus > 0
  • Tanggal format: YYYY-MM-DD (contoh: 2024-01-15)
  • Waktu format: HH:MM:SS (contoh: 10:30:00)
  • Angka format: Tanpa currency symbols (contoh: 25000, bukan Rp 25.000)
  • Boolean format: TRUE/FALSE untuk kolom void
  • Kolom opsional akan diisi default jika kosong

Common Issues & Solutions

Issue Cause Solution
"Missing required fields" Kolom wajib kosong atau quantity/net_price = 0 Isi kolom wajib dan pastikan quantity/net_price > 0
"Insufficient columns" Kurang dari 26 kolom Tambahkan kolom hingga 26 (bisa kosong untuk opsional)
"Date parsing failed" Format tanggal salah Gunakan format YYYY-MM-DD
"Time parsing failed" Format waktu salah Gunakan format HH:MM:SS
